# 0003 — Defer a Chinese UI

**Status:** Accepted · **Date:** 2026-07-15 · **Origin:** `docs/roadmap.md` (Later)

## Context

The studio's interface is English-only. A Chinese UI — at minimum for Translate and the landing
pages — was considered and deferred.

## Decision

Defer a Chinese UI. It remains a backlog item in `docs/roadmap.md` (Later), not current work.

## Alternatives considered

**Not recorded.** The original entry reads in full: *"Chinese UI (at least Translate + landing
pages) — decided to defer, 2026-07-15."*

## Consequences

- All user-facing copy stays English-only for now.
- No i18n framework, message catalogue, or locale routing has been introduced, so adopting one
  later is a greenfield choice rather than a migration.

## Rationale status

**Not recorded at the time.** No reasoning is preserved in the repository for why this was
deferred, only that it was and on what date. This record deliberately does not invent one. If
the reasoning matters to a future decision, it must be re-established with the owner rather
than reconstructed from this file.
